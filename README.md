# 🎓 Телеграм-бот «Школьный дневник» (Свердловская область)

Телеграм-бот для электронного школьного дневника Свердловской области ([dnevnik.egov66.ru](https://dnevnik.egov66.ru/)).

Удобное расписание, домашние задания, оценки и расписание звонков прямо в Telegram в один клик.

---

## 🌟 Возможности

- 🚀 **Быстрые кнопки внизу экрана (Reply Keyboard)**:
  - `🗓 Расписание [Класс]`
  - `На завтра` и `На сегодня`
  - `📋 Все оценки`
  - `✍️ Домашние задания` и `📋 Оценки на этой неделе`
  - `📄 Список команд`
- 🎨 **Красивое отображение оценок с цветными бейджами**:
  - 🟢 **5 / 4** (отлично / хорошо)
  - 🟡 **3** (удовлетворительно)
  - 🔴 **2 / 1** (неудовлетворительно)
- 📅 **Расписание уроков**: на любой день недели, сегодня, завтра со звонками и номерами кабинетов.
- ✍️ **Домашнее задание по дням**: интерактивное переключение дат кнопками `◀️` и `▶️`, показ прикрепленных файлов.
- 🔔 **Расписание звонков**: команда `/calls`.
- 👤 **Профиль ученика**: класс, школа, ФИО и команда удаления аккаунта `/delacc`.
- 🔒 **Шифрование данных**: токены авторизации шифруются в базе данных по стандарту **AES-256 (Fernet)**.
- 🔄 **Фоновый авторефреш токенов**: бот сам упреждающе обновляет токены по JWT-экспирации.
- 🐳 **Готовность к Docker**: `Dockerfile`, `docker-compose.yml`, `deploy.sh`.

## 🚀 Быстрый запуск

### 1. Локально на компьютере:
```bash
# 1. Активировать venv
source .venv/bin/activate

# 2. Скопировать .env.example
cp .env.example .env

# 3. Вставить ваш токен от @BotFather в .env
# TELEGRAM_BOT_TOKEN=...

# 4. Запустить бота
python bot.py
```

### 2. В Docker на сервере:
```bash
chmod +x deploy.sh
./deploy.sh
```

## 🔑 Как войти в бота

1. Откройте **dnevnik.egov66.ru** в браузере на компьютере и авторизуйтесь через Госуслуги.
2. Нажмите **F12** (или правый клик → *«Посмотреть код»*).
3. Перейдите в **Application** (Приложение) → **Local Storage** (Локальное хранилище) → `https://dnevnik.egov66.ru`.
4. Скопируйте значения **Auth__refresh** и **Auth__token**.
5. Нажмите кнопку **«Регистрация»** в боте и вставьте значения.
